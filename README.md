
# Мега Калькулятор 3000

Многофункциональный графический калькулятор, написанный на Python с использованием библиотеки Tkinter. Проект объединяет в себе возможности стандартного и инженерного калькулятора, конвертера единиц измерения, а также модуля для решения математических уравнений.

---

## Основные возможности

* **Инженерный калькулятор:**
* Базовые арифметические операции (`+`, `-`, `*`, `/`).
* Тригонометрические функции (`sin`, `cos`, `tan`).
* Вычисление квадратного корня (`√`) и возведение в степень (`^`).
* Поддержка скобок для управления приоритетом операций и константы Число Пи ($\pi$).


* **Конвертер величин:**
* Перевод расстояния: Километры <-> Мили.
* Перевод объема данных: Мегабайты (МБ) <-> Гигабайты (ГБ).


* **Решение уравнений:**
* Автоматический расчет дискриминанта и поиск действительных корней квадратных уравнений вида $ax^2 + bx + c = 0$.


* **Интерфейс:**
* Графический интерфейс с вкладками для удобного переключения между функциями.



---

## Требования

Для запуска приложения требуется только установленный **Python версии 3.x**.

*(Библиотека `tkinter` входит в стандартную комплектацию Python для Windows и macOS).*

## Установка и запуск

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/ваш-username/mega-calculator.git
cd mega-calculator

```


2. **Запустите программу:**
```bash
python mega_calculator.py

```



---

## Архитектура проекта

Приложение использует модульную структуру с использованием ООП (класс `MegaCalculator`), где каждая вкладка инициализируется в отдельном методе:

* `create_calc_tab()` — логика и интерфейс калькулятора.
* `create_converter_tab()` — конвертация величин.
* `create_equation_tab()` — математический модуль.
